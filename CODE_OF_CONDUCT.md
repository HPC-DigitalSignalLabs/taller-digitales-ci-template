# Código de conducta

Este proyecto adopta el
[Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: trato respetuoso, crítica técnica dirigida al código y no a las
personas, y cero tolerancia al acoso. Los incidentes se reportan en privado
a los mantenedores listados en [.github/CODEOWNERS](.github/CODEOWNERS).
